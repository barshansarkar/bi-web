A small web language
with a built-in HTTP server.

.bi is a compact programming language for writing web servers. It ships with routes, JSON, a tree-walking interpreter, and a pip-style package manager — in about 1,500 lines of C++17. No frameworks. No build step. No ceremony.

01 — install

Up and running in seconds

One line on Linux x86_64. Or build from source on any Linux or macOS machine.

One-line install linux · x86_64 
curl -fsSL https://github.com/barshansarkar/bi/raw/main/install.sh | bash

No dependencies. Detects your platform and drops the binary in /usr/local/bin.

From source any linux · macos 
git clone https://github.com/barshansarkar/bi
cd bi
make
sudo make install

Or use CMake: cmake -B build && cmake --build build -j.

Verify the installation 
$ bi version
bi 0.1.0

04 — web

A server in every file

Define routes, read request data, send responses. The HTTP server is part of the runtime — you never wire it up yourself.

Routes

route GET "/" {
  return "<h1>home</h1>"
}

route GET "/users/:id" {
  return "user " + params.id
}

route POST "/api/echo" {
  return json({ received: body })
}

route GET "/old" {
  redirect("/")
}

Methods: GET POST PUT DELETE PATCH · Segments starting with : are captured into params.

Request variables

reqmap — { method, path, body, headers, query }
paramsmap — /users/:id → { id: "42" }
querymap — ?name=ada → { name: "ada" }
bodystring — raw request body
methodstring — "GET", "POST", …
pathstring — path without query string

Response helpers

return "raw text"              // text/html
return json({ ok: true })      // application/json
return html("<h1>hi</h1>")     // explicit html

status(404)
header("X-Custom", "value")
redirect("/login")

Complete example — a todo API

let todos = []
let nextId = 1

route GET "/" {
  return "<h1>Todos</h1><p>See <a href='/api/todos'>/api/todos</a></p>"
}

route GET "/api/todos" {
  return json(todos)
}

route POST "/api/todos" {
  let text = query.text
  if (text == null) { text = "untitled" }
  let t = { id: nextId, text: text, done: false }
  nextId = nextId + 1
  todos.push(t)
  status(201)
  return json(t)
}

route GET "/api/todos/:id" {
  let id = num(params.id)
  for (let t in todos) {
    if (t.id == id) { return json(t) }
  }
  status(404)
  return json({ error: "not found" })
}

serve(8080)

Test it

06 — packages

A pip-style package manager

Install packages with one command. Manifests live in bi.json, packages land in bi_modules/.

Install & use

# install a package
bi install router

# point at your own registry
export BI_REGISTRY=https://packages.example.com

# use it
import "router"

route GET "/" {
  return router.name
}

Package commands

bi initcreate bi.json
bi installinstall all from bi.json
bi remove <pkg>uninstall
bi listlist installed
bi.json 
{
  "name": "myapp",
  "version": "0.1.0",
  "entry": "src/main.bi",
  "dependencies": {
    "router": "*"
  }
}

10 — status

Early prototype, honest about it

Version 0.1.0. Everything documented above works. Here's what doesn't, yet.

✓ Works

Everything documented above — the language, the HTTP server, routes, modules, and the package manager.

! Limitations

  • —No template literals yet — use "..." + var
  • —No HTTPS — put it behind nginx or Caddy
  • —No async I/O — thread-per-connection instead
  • —No GC — reference counting via std::shared_ptr
  • —Tree-walking interpreter — fine for prototypes
  • —Linux x86_64 binary only — macOS & ARM coming
